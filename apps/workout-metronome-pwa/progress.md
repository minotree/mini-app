# 운동 메트로놈 PWA 진행표

## 현재 상태 (2026-11-03)

- 구현: 실내·실외 선택, 공통 BPM 프리셋과 40~240 직접 템포 입력, 추 애니메이션, Web Audio 비트, 진동, 박자 묶음·강박·카운트인, 목표 운동 시간, 독립 재생 제어, 도움말, 로컬 설정 저장을 구현했다.
- 실외 속도: 운동 화면에서 브라우저 GPS 속도를 km/h로 표시한다. 속도 값이 없으면 `—`와 수신 상태를 표시하고, 오류 시 재시도를 제공한다. 기존 종목별 저장값은 템포를 유지하면서 기본 실내 환경으로 전환한다.
- 화면 구성: 운동 화면은 추·템포·남은 시간·재생 제어만 표시하고, 설정은 별도 화면에서 조절하도록 분리했다. 좁은 세로 화면에서는 재생 제어를 한 줄씩 배치하며, 도움말은 선택한 `?` 버튼 바로 아래에 표시하고 화면 가장자리에서 위치를 보정한다.
- 화면 흐름 변경(2026-11-03): 첫 화면을 운동 준비 홈으로 바꾸고 홈에서 환경·BPM·시간을 설정해 운동을 시작한다. 운동 화면의 설정 버튼은 세션을 일시정지하고 홈으로 돌아가며, 홈의 이어하기는 남은 시간부터 재생한다. 목표 시간 변경은 진행 중 세션에서 잠근다.
- 홈 UI 변경(2026-11-03): 앱 제목·브라우저 제목·PWA 표시 이름을 `모두의 비트`로 바꿨다. 템포는 현재 BPM을 크게 표시하고 프리셋을 3열로 정리했으며, 목표 시간도 3열 선택지와 직접 입력으로 구성했다. 시작·이어하기 버튼을 화면 하단에 고정했다.
- 홈 밀도 조정(2026-11-03): 스크롤을 줄이기 위해 헤더와 템포·시간 선택 영역을 압축하고 시간 프리셋을 기본 5열로 배치했다. 직접 입력·박자 묶음·소리·진동·카운트인은 `세부 설정` 펼침 영역으로 옮겼다. 작은 화면과 펼친 상태에서는 스크롤을 허용한다.
- 인터벌 추가(2026-11-03): 홈의 펼침 영역에 일반 운동, 짧은 반복(빠른 1분·회복 1분 × 10회), 균형 반복(빠른 3분·회복 2분 × 5회), 사용자 설정을 추가했다. 사용자 설정은 구간별 시간·BPM·반복 횟수를 로컬에 저장한다. 운동 화면은 구간·회차·구간 남은 시간과 BPM을 표시하며 완료까지 자동 전환한다. 일시정지·재개는 전체 남은 시간을 유지한다.
- 프리셋 상세 표시(2026-11-03): 짧은 반복과 균형 반복도 사용자 설정과 동일한 5개 항목을 읽기 전용 칸으로 표시한다. 요약 시간도 현재 선택된 계획에서 계산한다.
- 사용자 설정 범위 표시(2026-11-03): 각 입력 항목 제목 옆에 허용 범위를 표시하고 입력 접근성 이름에도 범위를 포함했다.
- iPhone Safari 화면 잠금 제보(2026-11-03): 사용자가 화면을 끄면 앱이 작동하지 않는 듯하다고 보고했다. 인터벌의 오디오 예약이 0.3초에 불과해 타이머 지연에 취약한 점을 확인하고 구간별 BPM을 계산하며 20초 앞까지 예약하도록 수정했다. 복귀 시 오디오 컨텍스트가 중단 상태면 운동을 일시정지하고 중단 메시지를 표시한다. 실제 잠금 상태 재생은 Safari·iOS 정책에 따라 중단될 수 있으며 이번 수정만으로 연속 재생을 보장하지 않는다. 동일 기기에서 재검증이 필요하다.
- 운동 완료 화면(2026-11-03): 남은 시간이 0이 되면 완료 화면으로 이동해 설정한 환경·전체 시간·템포 또는 인터벌 구성을 보여 준다. 같은 설정으로 다시 시작하면 시간과 박자를 초기화해 운동 화면에서 시작하고, 설정 바꾸기는 같은 설정을 유지한 홈으로 돌아간다. 전면 광고 연동은 미구현이며 정상 완료 뒤의 별도 후속 작업으로 둔다.
- 헤더 통일(2026-11-03): 홈·운동·완료 화면의 헤더에서 같은 로고와 제목을 표시하도록 바꿨다. 운동 화면에만 오른쪽 설정 버튼을 두고, 홈의 중복 설명 문구를 제거해 높이를 통일했다.
- 펼침 메뉴 좌우 흔들림 보정(2026-11-03): 인터벌·세부 설정을 열고 닫을 때 세로 스크롤바 생성 여부에 따라 중앙 정렬 화면이 이동하지 않도록 루트에 안정적인 양쪽 스크롤바 여백을 예약했다. 실제 브라우저에서 재확인 필요.
- 표시 언어 정리(2026-11-03): 공통 헤더의 영문 `MODUI BEAT`를 제거하고 `모두의 비트`만 표시한다. 완료 화면의 영문 문구도 한국어로 바꿨다.
- 운동 상태 문구 정리(2026-11-03): 화면 켜짐 유지 상태를 짧게 표시하고, 긴 화면 잠금 오디오 설명은 운동 화면에서 제거했다. 잠금 재생 한계는 작업 지침과 개발 문서에 유지한다.
- 세부 설정 문구 정리(2026-11-03): 하단의 긴 진동·재생 안내 문구를 제거했다. 진동 지원 설명은 해당 도움말에 남겨 두었다.
- 비트 소리 선택(2026-11-03): 세부 설정에 `똑딱`·`비프`·`우드` 선택과 미리 듣기를 추가했다. 세 소리는 외부 파일 없이 Web Audio 발진기와 엔벌로프로 직접 합성하며 로컬 설정에 저장한다. 기존 저장 데이터는 `똑딱`을 사용한다. 출처·권리 검토: 외부 음원·녹음·이미지를 사용하지 않았으며 코드에서 생성하는 소리다(2026-11-03). 실제 기기 음질·볼륨은 미검증이다.
- 구간 전환 호르라기(2026-11-03): 인터벌 세부 설정에 기본 꺼짐 옵션을 추가했다. 켜면 짧은 합성음을 미리 듣고, 비트 소리가 켜진 운동 중 빠른·회복 구간 전환 때만 울린다. 첫 구간과 같은 구간 재개에서는 울리지 않는다. 외부 음원 없이 Web Audio로 생성한다. 실제 기기에서 구간 경계·음량·화면 전환 동작은 미검증이다.
- 호르라기 자동 검증: 타입 검사·단위 검사 8개·`git diff --check`를 통과했다. 첫 구간·같은 구간 재개·구간 전환의 알림 조건을 단위 검사에 포함했다.
- 실외 정보 배치와 날씨(2026-11-03): 추 왼쪽에 GPS 속도, 오른쪽에 위치 기반 기온·날씨 예보를 배치했다. 사용자가 `날씨 조회`를 누르면 반올림한 좌표(소수점 2자리)를 MET Norway Locationforecast API에 전송한다. 외부 전송과 IP 전달을 조회 전 안내하고, 출처·CC BY 4.0 링크를 표시한다. 응답이 없으면 실패 상태와 재시도를 보여 준다. 약 30분 간격으로 갱신한다. 기상 데이터·이용 조건 확인: [MET Norway API](https://api.met.no/weatherapi/locationforecast/2.0/documentation), [이용 약관](https://api.met.no/doc/TermsOfService), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) (2026-11-03). 실제 브라우저의 CORS·조회·세로 레이아웃은 미검증이다.
- 배포 전 빌드 검증(2026-11-03): 타입 검사와 단위 검사 10개를 통과했다. 기존 `path-scurry`→`lru-cache` 로컬 연결 오류는 잠금 파일을 유지한 `pnpm.cmd install --frozen-lockfile --ignore-scripts`로 의존성을 재구성해 해결했다. `pnpm.cmd --filter @mini-apps/workout-metronome-pwa build`가 통과하고 `dist/sw.js`·Workbox 파일·한국어 매니페스트가 생성됐다. Vite 프로덕션 미리보기에서 `/`, `/sw.js`, `/manifest.webmanifest`, Workbox 파일 모두 HTTP 200을 확인했다. 실제 PWA 설치·오프라인 동작·실기기 GPS·날씨 API CORS는 미검증이며 커밋·푸시·배포는 하지 않았다.
- 운동 제어 도움말 아이콘(2026-11-03): 재생 제어 영역의 일반 버튼 너비 규칙이 `?` 버튼에도 적용돼 좁아지는 문제를 수정하고, 도움말 버튼을 고정 원형 크기로 표시했다. 실제 좁은 화면에서 재확인 필요.
- 운동 제어 줄바꿈 보정(2026-11-03): 세 제어 버튼의 가로 공간을 균등하게 배분하고 버튼 글자가 한 줄에 표시되도록 여백·글자 크기를 조정했다. 좁은 화면에서는 기존 세로 배치를 유지한다.
- 운동 제어 도움말 크기 조정(2026-11-03): 원형 `?` 버튼을 2rem에서 1.75rem으로 줄이고 고정 크기는 유지했다.
- 모든 도움말 줄바꿈 보정(2026-11-03): 운동 제어 3개와 설정 영역의 모든 `?`가 공통 `HelpTip`을 사용함을 확인했다. 공통 말풍선 폭을 최대 20rem으로 넓히고 위치 계산을 같은 폭에 맞췄으며, 한글 단어가 중간에서 분리되지 않도록 줄바꿈 규칙을 적용했다. 실제 좁은 화면 확인은 남아 있다.
- 도움말 선택 상태(2026-11-03): `?` 버튼의 `aria-expanded`가 참일 때 배경과 글자색을 반전해 열림 상태를 표시한다. 닫으면 기본색으로 돌아간다.
- 완료 화면 자동 검증: 타입 검사·기존 단위 검사 7개·`git diff --check`를 통과했다. 실제 브라우저의 완료 전환·재시작·설정 복귀는 미검증이다.
- 인터벌 자동 검증: 타입 검사, 단위 검사 7개, `git diff --check`를 통과했다. 구간 경계의 BPM 변경과 사용자 설정 보정은 단위 검사로 확인했다. 브라우저의 실제 오디오·애니메이션·일시정지·재개·완료·GPS 결합은 미검증이며, PWA 빌드는 반복 UI 단계라 실행하지 않았다.
- 이번 UI 변경 검증: 타입 검사와 기존 단위 검사 5개, `git diff --check`를 통과했다. 실제 모바일 브라우저에서 하단 고정 영역과 프리셋 배치는 아직 확인하지 못했다. PWA 빌드는 반복 UI 개발 단계라 재실행하지 않았다.
- 도움말 닫기: 설명 패널의 닫기 버튼, 패널 밖 터치·클릭, Esc, 화면 전환으로 도움말을 닫을 수 있게 했다.
- 재생 보완: 20초 선행 오디오 예약, Media Session 제어, Screen Wake Lock 상태·해제를 구현했다.
- 배포: `mini-apps-workout-metronome`의 GitHub Workers Builds production 연결이 완료됐고, 공개 URL은 `https://mini-apps-workout-metronome.minotree0902.workers.dev`다.
- 초기 화면 전환 검증 이력: 홈→운동 화면 전환 수정 당시 타입 검사와 단위 검사 5개를 통과했고, Vite 개발 서버의 응답을 확인했다. 그때 실패했던 PWA 빌드는 위의 배포 전 빌드 검증에서 해결했다.
- 검증 순서 결정(2026-11-03): 반복 UI 개발 중 Vite 화면·타입·단위 검사를 먼저 확인하고, 기능을 일정 단위로 정리한 뒤 PWA 빌드와 서비스 워커를 재검증한다. 이 순서는 다른 앱에도 공통 적용한다.

## 미검증 및 다음 작업

- Android·iOS에서 오디오, 진동, Screen Wake Lock, 화면 잠금·백그라운드 전환, PWA 설치·서비스 워커를 검증한다.
- 실제 좁은 세로 화면에서 운동/설정 전환, 재생 제어 버튼, 도움말 패널의 가독성과 터치 동작을 검증한다.
- 홈 시작→카운트인→운동, 설정 복귀·이어하기, 카운트인 중 복귀, 목표 시간 잠금과 운동 완료·초기화 흐름을 브라우저에서 확인한다.
- 실제 기기에서 실외 위치 권한·GPS 속도·속도 값 없음·오류 재시도 및 실내/설정 전환 시 위치 감시 중지를 검증한다.
- 토스 미니앱 SDK·권한·실기기 환경에서 화면 잠금·백그라운드 비트 재생을 별도로 검증하고, PWA 결과와 혼용하지 않는다.
- 워밍업·인터벌·음성 응원은 현재 범위 밖이며, 필요 확정 뒤 별도 요구사항으로 다룬다.
