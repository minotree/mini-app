# 운동 메트로놈 PWA 작업 지침

루트 [AGENTS.md](../../AGENTS.md)의 공통 정책을 먼저 적용한다. 이 문서는 `@mini-apps/workout-metronome-pwa`의 제품 범위와 플랫폼별 검증 기준의 단일 기준이다.

## 목표와 범위

- 실내·실외 환경 선택과 공통 BPM 프리셋·직접 템포 조절, 실제 메트로놈 추 왕복 애니메이션, Web Audio API 합성 비트, 선택형 진동을 제공한다.
- 비트 소리는 직접 합성한 `똑딱`·`비프`·`우드` 중 고르고 로컬에 저장한다. 기본값과 기존 저장 데이터의 대체값은 `똑딱`이며, 선택 시 미리 듣기를 제공한다.
- 인터벌 구간 전환 호르라기는 기본 꺼짐의 별도 옵션이다. 켜면 짧은 합성음을 미리 들려주며, 운동 중에는 비트 소리가 켜진 상태에서 구간이 바뀔 때만 울린다. 시작과 일시정지 후 같은 구간 재개에서는 울리지 않는다.
- 실외 운동 화면에서는 추 왼쪽에 브라우저 GPS 속도를 km/h로 표시한다. GPS 속도 값이 없거나 권한이 거부되면 추정값을 만들지 않고 상태를 안내한다. 설정 화면·실내 전환 시 위치 감시를 해제한다.
- 추 오른쪽의 날씨는 사용자가 `날씨 조회`를 누른 뒤에만 MET Norway의 위치 예보 API에 소수점 둘째 자리로 반올림한 좌표를 보내 조회한다. GPS 속도와 원본 좌표는 전송하지 않는다. 제공기관·CC BY 4.0 출처를 화면에 표시하고, 실패하면 예보를 지어내지 않는다. 약 30분 간격으로 갱신한다.
- 적용 안 함·2·3·4박 묶음과 첫 박 강조, 선택형 4박 카운트인, 10~240분 목표 운동 시간과 남은 시간, 시작·일시정지·초기화, 로컬 설정 저장을 제공한다.
- 첫 화면은 운동 준비 홈으로 두고, 홈에서 환경·BPM·시간·소리 등을 설정한 뒤 운동을 시작한다. 운동 화면은 추·상태·재생 제어에 집중하며 설정 버튼을 누르면 일시정지 상태로 홈에 돌아가 남은 시간부터 이어할 수 있다. 목표 시간 변경은 세션 초기화 후 허용한다.
- 화면과 설치형 PWA에 표시하는 앱 이름은 `모두의 비트`로 한다. 홈의 시작·이어하기는 설정을 스크롤해도 사용할 수 있도록 하단에 고정한다.
- 홈·운동·완료 화면은 같은 높이와 `모두의 비트` 제목의 공통 헤더를 사용한다. 운동 화면에서만 헤더 오른쪽에 설정 버튼을 둔다.
- 홈의 기본 화면은 환경·템포·목표 시간·시작에 집중하고, 직접 입력·박자·소리·진동·카운트인은 펼침 영역에서 조절한다. 작은 화면에서는 필요한 경우 스크롤을 허용한다.
- 인터벌은 실내·실외에서 공통으로 사용한다. `사용 안 함`, 짧은 반복, 균형 반복, 사용자 설정 중 하나를 고르며 사용자 설정은 빠른·회복 구간의 시간과 BPM, 반복 횟수를 저장한다. 시작 후에는 인터벌 구성을 잠그고 현재 구간·회차·구간 남은 시간을 운동 화면에 표시한다.
- 짧은 반복·균형 반복을 선택해도 사용자 설정과 같은 항목별 값을 보여 준다. 프리셋 값은 읽기 전용이며 사용자 설정만 편집할 수 있다.
- 목표 시간이 끝나면 완료 화면에 운동 환경·설정한 전체 시간·템포 또는 인터벌 구성을 표시한다. 같은 설정으로 다시 시작하거나 홈에서 설정을 바꿀 수 있다. 전면 광고를 연동할 경우 정상 완료 뒤에만 고려하며, 광고가 없어도 완료 화면에 접근할 수 있어야 한다.
- 워밍업, 사용자 문구 관리, 음성 응원·MP3 생성, 토스·Android·iOS 구현은 현재 범위에서 제외한다. 첫 출시는 토스 미니앱을 우선하지만 PWA 구현을 토스 호환 근거로 사용하지 않는다.

## 재생과 접근성

- 기본 시각 피드백은 플래시가 아닌 실제 추 움직임이다. `prefers-reduced-motion` 사용자는 정지 표시를 이용할 수 있어야 한다.
- 재생 중 Screen Wake Lock을 요청하고 일시정지·초기화·운동 종료에서 해제한다. 시스템 해제와 미지원 상태를 표시하며 화면 유지나 백그라운드 재생을 보장한다고 주장하지 않는다.
- 활성 재생에는 Web Audio 20초 선행 예약과 Media Session 제어를 사용한다. OS·브라우저 중단·프로세스 종료 및 토스 런타임 지원은 각각 실기기에서 검증한다.
- iPhone Safari의 화면 잠금·앱 전환에서 Web Audio가 중단될 수 있다. 지원 환경에서는 운동 시작 시 `navigator.audioSession.type = 'playback'`을 설정하지만 잠금 중 재생을 보장하지 않는다. 복귀 시 오디오가 중단됐으면 일시정지와 재개 안내를 제공한다. 화면 잠금 재생을 출시 요건으로 판단할 때는 실기기 확인 후 별도 재생 방식이나 플랫폼 구현을 결정한다.

## 배포와 검증

- `wrangler.jsonc`는 `mini-apps-workout-metronome` Worker에서 `dist`를 제공한다. GitHub Workers Builds와 production URL `https://mini-apps-workout-metronome.minotree0902.workers.dev`가 연결돼 있다.
- Build watch include paths는 `apps/workout-metronome-pwa/*`, `package.json`, `pnpm-lock.yaml`, `pnpm-workspace.yaml`이다(2026-11-03 사용자 제공 Cloudflare 설정 화면 기준). 변경은 사용자와 배포 영향을 확인한 뒤에만 한다. 커밋·푸시·직접 배포·계정과 비밀값 변경도 명시 승인 후에만 한다.
- 개발은 `pnpm.cmd dev:metronome`, 타입 검사·단위 검사·빌드는 각각 `pnpm.cmd --filter @mini-apps/workout-metronome-pwa typecheck`, `test`, `build`를 사용한다.
- 검증 순서는 루트 `AGENTS.md`의 전체 앱 공통 원칙을 따른다.
