# Golf PWA 작업 지침

루트 [AGENTS.md](../../AGENTS.md)의 공통 정책을 먼저 적용하고, 구현 전 [Golf PRD/TRD](../../docs/planning/golf-app-prd-trd-spec.md)의 ‘현재 우선 구현 범위’를 읽는다.

## 목표와 범위

- 사용자는 클럽만 선택하고 카메라 배치 안내에 따라 스윙한다. 앱은 영상에서 클럽 헤드 속도·임팩트 각도·볼 스피드 등을 자동 산출해 방향각과 비거리를 추정하는 런치 분석 MVP를 지향한다.
- 현재는 클럽 선택, 카메라 권한·미리보기, 측면 카메라 배치 안내, Web Speech API 준비 안내, 런치 계산의 순수 규칙과 단위 검사가 구현 범위다.
- 스윙 모션·포즈 분석은 후속 범위다. 수치 수동 입력, 복잡한 측정 시작 조작, 측정값이 없을 때 결과 표시는 제공하지 않는다.

## 신뢰도와 콘텐츠 기준

- 측정 신뢰도, 표준 환경 가정, 지원 기기 및 카메라 보정 한계를 표시하지 않은 채 방향각·비거리를 확정값으로 주장하지 않는다.
- 카메라는 공 진행 방향의 측면에서 공과 임팩트 구간이 보이도록 둔다. 실제 거리·높이·화각은 검증 전 기준값으로 단정하지 않는다.
- 외부 모델·영상·이미지·음성·물리 데이터는 권리·라이선스·배포 조건 확인 전 포함하지 않는다. Web Speech API의 실제 기기 동작도 별도 검증한다.

## 배포와 검증

- `wrangler.jsonc`는 `mini-apps-golf` Static Assets Worker 설정이다. 2026-11-03 사용자 제공 Cloudflare 대시보드 화면에서 Worker 생성·GitHub 연결·배포 이력을 확인했다. 향후 직접 배포·설정 변경은 명시 승인 후에만 진행한다.

| Key | Value |
| --- | --- |
| 실행 위치 | `D:\DEV\mini-apps` |
| 개발 서버 | `pnpm.cmd dev:golf` → `http://127.0.0.1:5180/` |
| 타입 검사 | `pnpm.cmd --filter @mini-apps/golf-pwa typecheck` |
| 단위 검사 | `pnpm.cmd --filter @mini-apps/golf-pwa test` |
| 빌드 | `pnpm.cmd --filter @mini-apps/golf-pwa build` |

- 반복 개발과 기능 정리 후 PWA 빌드의 검증 순서는 루트 `AGENTS.md`의 공통 원칙을 따른다.
- 실제 카메라 권한·미리보기, 음성 안내, 타구·볼·클럽 헤드 추적, 측정 정확도는 자동 검사와 분리해 기록한다.
